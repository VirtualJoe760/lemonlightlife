# Claude Code project context

**Read `AGENTS.md` at the repo root first.** It is the canonical project-
context file for both humans and agents, and it points to the full
architecture in `/docs/architecture/`. This file is intentionally short —
everything you need to work in this repo lives in `AGENTS.md` and the docs
it references, so a single source of truth stays in sync.

## Quick pointer

- `AGENTS.md` — stack, workflow, file layout, conventions, dev commands
- `/docs/architecture/` — full system design, one file per topic
- `/docs/architecture/README.md` — index of the architecture docs
